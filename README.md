Weapon Run Binder for Monster Hunter Frontier

Lets you set any keyboard key or XInput/DInput button as a weapon run bind, blocks double stick flick from weapon running. Also saves your binds.


DONT PLAY WITH THIS ON A PUBLIC SERVER. Currently it only works with Switch Axe and in it's current implementation let's you do some pretty busted things. I'll be working on adding protection so you can only weapon run when you're supposed to be able to. 

Requires PaxModLoader
